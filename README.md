## Tutorial on data parallelism via SIMD (Single Instruction, Multiple Data) vector instructions. 

The presentation [**slides**](/Vectorization_tutorial.pdf) provides an overview of:
* the von Neumann architecture or model and Flynn's taxonomy of parallel architectures
* Moore's law, its important for modern computing, and its limits 
* The increasing demand for large-scale computations and parallel computing
* SIMD vectorization and data parallelism
